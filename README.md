# Creative Portfolio — Alex Morgan

Live demo site: a personal portfolio with a working project filter and
contact form.

**What actually works (in your browser, no server needed):**
- Project filter (All / Web / Brand / Apps) over real project data
- Contact form that validates and stores messages in localStorage
- Skills bars, project grid, booking call-to-action

**Honest limits:** static front-end. Messages are stored in the visitor's
browser only. "Alex Morgan" is a sample persona. Connect a form backend or
email service to receive messages for real.
